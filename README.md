# MATCH AI — футбольная аналитика

Полностью русскоязычное Android-приложение в тёмном премиальном стиле.

## Возможности
- Расписание матчей на сегодняшнюю дату по всем лигам, доступным в API-Football.
- Поиск по названию команды и лиги.
- Расширенный набор рынков: победа/ничья/поражение, двойной шанс, тоталы голов 0.5/1.5/2.5/3.5, обе забьют, гол в первом тайме, исход к перерыву, индивидуальные голы команд.
- Статистика по угловым, жёлтым карточкам, ударам, ударам в створ и фолам — если эти данные доступны в API для последних матчей.
- Русский интерфейс, локальное хранение API-ключа, время по часовому поясу телефона.

## Получение APK через GitHub Actions
1. Создайте пустой репозиторий на GitHub.
2. Загрузите в репозиторий все файлы этого проекта.
3. Откройте вкладку **Actions**.
4. Выберите **Сборка MATCH AI APK** и нажмите **Run workflow** либо сделайте push в `main`/`master`.
5. После успешной сборки откройте запуск workflow и скачайте артефакт `MATCH-AI-debug`. Внутри будет APK для установки на Android.

## Подключение матчей и статистики
Приложение использует API-Football (API-Sports): https://www.api-football.com/
В приложении нажмите **Настройки API**, вставьте свой API-ключ и сохраните его. Ключ хранится локально на устройстве.

Доступность лиг, статистики и число запросов зависят от тарифа API. Для каждого уникального клуба приложение запрашивает последние пять матчей, а для статистики угловых/карточек/ударов анализирует статистику последних трёх завершённых матчей. Это может расходовать лимит API; на бесплатном тарифе обновление большого списка матчей может быть ограничено.

## Важное о прогнозах
Это не профессиональная ML-модель. Проценты 1X2, тоталов, голов в тайме и индивидуальных голов являются упрощёнными статистическими оценками по последним результатам. Угловые, карточки, удары, удары в створ и фолы отображаются как средние значения из API, если статистика доступна. Если API не предоставляет показатель, приложение честно показывает «Нет данных». Ни один прогноз не гарантирует исход матча.
